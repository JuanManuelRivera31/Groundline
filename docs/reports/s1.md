## Decisions taken autonomously

- TypeScript 6.0.3 instead of 7.0. Postgres 18 instead of 19. No compile step for CLIs. Host port 54329.
- `top-level` request shape by default, switchable with `GEMINI_EMBED_REQUEST_SHAPE=config`.
- Default batch of 20, capped by RPM and by half the TPM budget, with a 1.2 token safety factor.
- Task type is part of the cache key.
- Every attempt is recorded in `api_usage` with its HTTP status.
- A run that would exceed the daily quota fails before its first call. Batches are cached as they arrive, so an interrupted run resumes without re-spending quota.
- Small descendant sections fold into their parent. Search is filtered by embedding model.
- Extra offline `pnpm chunks:stats` CLI.
- gitleaks-action replaced by the pinned CLI.
- Bug fixed: the working tree was empty after a `--no-checkout` clone.
